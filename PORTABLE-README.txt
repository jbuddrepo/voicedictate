VoiceDictate Portable 0.1.1 Beta

1. Extract the entire ZIP to a folder.
2. Keep VoiceDictate.exe, both worker executables, and the resources folder together.
3. Run VoiceDictate.exe.

Settings and text-only history are stored in the current Windows user's application-data folder. Audio is removed after transcription. This beta is unsigned, so Windows may show an Unknown Publisher warning.

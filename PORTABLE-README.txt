VoiceDictate Portable 0.2.0 Beta

1. Extract the entire ZIP to a folder.
2. Keep VoiceDictate.exe, both worker executables, and the resources folder together.
3. Run VoiceDictate.exe.

Settings and text-only history are stored in the current Windows user's application-data folder. Audio is removed after transcription. Remote transcription sends audio only to the server configured by the user. This beta is unsigned, so Windows may show an Unknown Publisher warning.

See REMOTE-TRANSCRIPTION.md for step-by-step K11, Linux, Docker, LAN, Tailscale, and hosted-provider setup. VIDEO-GUIDE.md provides a safe installation-video checklist.

# Contributing

Contributions are welcome. Please keep the core application account-free, telemetry-free, and usable entirely offline.

Before opening a pull request:

1. Run the frontend and Rust tests.
2. Verify a baseline AVX worker still runs without AVX2 or FMA requirements.
3. Avoid logging dictated text, API keys, endpoint credentials, or audio.
4. Add tests for changes to hotkeys, audio processing, providers, history, or URL security.
5. Update third-party notices when dependencies or bundled assets change.

By contributing, you agree that your contribution is licensed under Apache-2.0.
